# 카드 이미지 출처

이 프로젝트의 카드 이미지는 **Pamela Colman Smith가 그린 오리지널 Rider–Waite–Smith(RWS) 카드**의 스캔입니다. 메이저 아르카나 22장과 마이너 아르카나 56장, 총 78장을 사용합니다.

유니버설 웨이트(Universal Waite)는 동일한 RWS 도상에 Mary Hanson-Roberts가 새롭게 채색한 판본입니다. 이 프로젝트는 그 판본의 채색 이미지라고 표시하지 않습니다. 카드의 구성과 상징은 RWS 체계를 따르며, 실제 이미지에는 공개된 오리지널 스캔을 사용합니다.

- 작품: Rider–Waite–Smith tarot deck, “Pam-A”
- 그림: Pamela Colman Smith
- 구성: Arthur Edward Waite
- 출처: [Wikimedia Commons의 TaionWC 스캔 세트](https://commons.wikimedia.org/wiki/Category:Rider-Waite-Smith_tarot_deck_(TaionWC))
- Commons에 표시된 이미지 이용 조건: Public domain
- 표기 확인 예시: [The Fool](https://commons.wikimedia.org/wiki/File:RWS_Tarot_00_Fool.jpg), [Ace of Wands](https://commons.wikimedia.org/wiki/File:Wands01.jpg)
- 판본 구분 참고: [U.S. Games의 Universal Waite 공식 소개](https://www.usgamesinc.com/tarot-and-inspiration/pamela-colman-smith/universal-waite-r-tarot-deck.html)

`public/cards/sources.json`에 카드별 원본 파일명, Commons 설명 페이지, 다운로드 URL, 이미지 크기, 라이선스 표기를 기록했습니다. 이미지 파일은 Commons의 가로 500px 썸네일을 내려받아 로컬에서 제공합니다. 카드 화면은 외부 이미지 서버에 의존하지 않습니다. 스캔의 색상이나 선화를 재편집하지 않았습니다.

## 파일 이름

- `major-00.jpg`–`major-21.jpg`: 바보부터 세계까지, RWS 번호 순서. 힘은 VIII, 정의는 XI입니다.
- `wands-01.jpg`–`wands-14.jpg`: 완드
- `cups-01.jpg`–`cups-14.jpg`: 컵
- `swords-01.jpg`–`swords-14.jpg`: 소드
- `pentacles-01.jpg`–`pentacles-14.jpg`: 펜타클

각 수트의 `01`은 에이스, `02`–`10`은 숫자 카드, `11`은 시종(Page), `12`는 기사(Knight), `13`은 여왕(Queen), `14`는 왕(King)입니다.
