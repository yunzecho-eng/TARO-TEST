# TARO TEST · 나를 읽는 시간

양력 생일에서 찾은 타로 카드로 성격·세운·앞으로 10년의 흐름을 돌아보고, 직접 카드를 골라 운세를 읽는 한국어 웹페이지입니다. 아이보리와 짙은 녹색을 중심으로 단순하게 구성했습니다.

## 웹페이지

[**TARO TEST 웹페이지 열기**](https://taro-test-yunzecho.yunze-cho.chatgpt.site)

GitHub 저장소는 공개입니다. 현재 웹페이지는 소유자만 접속할 수 있도록 설정되어 있으며, 링크 공유만으로 다른 사람의 접속 권한이 생기지는 않습니다.

## 할 수 있는 일

- **나의 성격:** 생년월일로 메이저 카드 한 장을 계산합니다.
- **올해의 세운:** 선택한 연도와 생일의 월·일로 메이저 카드 한 장을 계산합니다.
- **10년의 흐름:** 시작 연도부터 연속 10년의 세운 카드를 계산하고, 각 연도를 눌러 해설을 읽습니다. 이 프로젝트에서 대운은 이 연도별 카드 흐름을 뜻합니다.
- **카드 뽑기:** 78장 중 무작위로 펼친 12장에서 3장을 골라 ‘현재 상황 · 살펴볼 점 · 실천할 조언’을 읽습니다. 카드가 중복되지 않으며, 정방향·역방향은 이 뽑기 운세에 적용합니다.
- **네 가지 해설자:** 타로집 선생님, 심리 상담사, 친한 친구, 학교 선생님의 말투를 선택하고 결과 화면에서도 바꿀 수 있습니다.
- **주제와 추가 질문:** 전체적인 흐름, 사람과 관계, 일과 공부, 내 마음의 관점으로 읽고, 강점·주의점·작은 실천·성찰 질문을 이어서 살펴봅니다.
- **78장 카드 도감:** 이름과 키워드 검색, 메이저·슈트별 분류, 정방향·역방향 해설을 제공합니다.
- **나의 기록:** 메모와 리딩을 브라우저에 최대 30개 저장하고 다시 읽거나 삭제합니다.

해설은 직접 작성한 카드별 문장과 말투별 템플릿으로 구성됩니다. **AI 생성이나 자유 입력 질문에 답하는 기능은 없습니다.** 메모는 해설에 반영되지 않습니다. 카드의 상징은 자기 성찰과 즐거움을 위한 것이며, 상담사 말투는 실제 심리 상담이나 진단을 제공하지 않습니다.

## 카드 계산 방법

먼저 세 숫자를 더한 뒤, **첫 합계의 각 자릿수를 반드시 한 번 더합니다.** 그 결과가 **22 이상이면** 다시 자릿수를 더해 1~21의 번호를 얻습니다. 22는 바보 카드로 바꾸지 않고 **2 + 2 = 4**로 계산합니다.

| 리딩 | 처음 더하는 숫자 |
| --- | --- |
| 성격 | 태어난 연도 + 태어난 달 + 태어난 날 |
| 세운 | 보고 싶은 연도 + 태어난 달 + 태어난 날 |
| 10년 흐름 | 시작 연도부터 10년 동안 각 연도의 세운을 개별 계산 |

예시:

```text
2026년 · 11월 7일 생일
2026 + 11 + 7 = 2044 → 2 + 0 + 4 + 4 = 10 → 운명의 수레바퀴

1970년 7월 7일 성격 카드
1970 + 7 + 7 = 1984 → 1 + 9 + 8 + 4 = 22 → 2 + 2 = 4 → 황제
```

성격·세운·대운처럼 생일로 계산한 카드에는 방향 개념을 적용하지 않습니다. 정방향·역방향은 무작위로 카드를 뽑는 운세에서만 사용하며, 기본 설정은 역방향을 포함합니다. 바보를 포함한 메이저 22장과 마이너 56장은 도감에서 모두 볼 수 있습니다. 올해와 기록 날짜는 `Asia/Seoul` 기준입니다. 성격 계산은 실제 출생 날짜를 검증하고, 세운 계산은 대상 연도가 평년이어도 2월 29일 생일을 허용합니다.

## 실행과 확인

Node.js 22.13 이상과 npm이 필요합니다. 프로젝트 디렉터리에서 실행합니다.

```sh
npm run install:ci
npm run dev
```

개발 서버가 출력하는 주소를 열면 됩니다. 기본 로컬 주소는 `http://localhost:5173`입니다. 다른 포트를 쓰려면 `npm run dev -- --port 5174`처럼 지정합니다.

```sh
npm test
npm run typecheck
npm run build
npm start
```

`npm test`는 계산 경계값, 2월 29일, 잘못된 날짜, 서울의 연도 변경 시점, 78장 데이터와 이미지, 페르소나별 해설을 확인합니다. `npm run typecheck`는 TypeScript를 검사합니다. `npm run build`는 배포 산출물을 만들고, `npm start`는 만들어진 Worker를 로컬에서 실행합니다. 로컬 실행 명령 자체는 사이트를 게시하지 않습니다.

React와 TypeScript로 작성했고 Vinext/Vite 및 Cloudflare Worker 기반의 Sites 실행 구조를 사용합니다. 생성되는 `dist/`, `node_modules/`, `.vinext/`, `.wrangler/`, `.sites-runtime/`는 Git에 포함하지 않습니다.

## 프로젝트 구조와 해설 확장

| 경로 | 역할 |
| --- | --- |
| `app/page.tsx` | 입력, 카드 펼치기, 결과, 도감, 기록 화면 |
| `app/globals.css` | 반응형 레이아웃과 스타일 |
| `lib/tarot.ts` | 78장 카드 데이터와 기본 페르소나 해설 |
| `lib/reading.ts` | 생일 계산, 연도 처리, 주제별 해설과 추가 질문 |
| `tests/reading.test.ts` | 계산과 데이터의 자동 검증 |
| `public/cards/` | 로컬에 포함한 78장 이미지와 출처 목록 |
| `docs/card-art.md` | 카드 이미지 출처와 사용 범위 |
| `.openai/hosting.json` | Sites 프로젝트 식별자와 배포 설정 |

해설을 확장할 때는 `lib/reading.ts`의 `getTopicReading(card, reversed, persona, topic, showDirection)`과 `getFollowUp(card, reversed, persona, question, showDirection)`을 중심으로 수정하면 됩니다. 두 함수는 카드·페르소나·질문을 받아 텍스트를 반환하는 템플릿 경계입니다. 계산형 리딩에서는 `showDirection=false`로 호출하여 방향을 적용하거나 언급하지 않습니다. 기본값 `true`는 카드 뽑기 운세용입니다. 화면과 계산 함수를 유지하면서 주제나 대화 문구를 개선할 수 있습니다. 성격·세운 계산은 `calculatePersonalityCard`와 `calculateYearCard`, 10년 흐름은 `calculateDecadeCards`에 분리되어 있습니다.

## 기록과 개인정보

입력한 생일과 메모를 애플리케이션 서버로 전송하지 않습니다. 계산과 해설은 브라우저에서 처리됩니다. ‘나의 기록에 저장’을 눌렀을 때만 `localStorage`의 `taro-test.readings.v1`에 리딩과 메모를 저장합니다. 저장된 계산식에는 입력한 생일 정보가 포함되므로, 같은 브라우저 프로필을 쓰는 사람이 기록을 볼 수 있습니다.

기록은 기기나 브라우저 사이에 동기화되지 않으며 브라우저 데이터를 지우면 사라집니다. 기록 화면에서 개별 삭제할 수 있고, 저장 공간을 사용할 수 없으면 화면에 실패를 알립니다. GitHub 저장소는 공개하고 Sites 사이트는 비공개로 운영합니다. 사이트 접근 범위는 Sites의 접근 설정으로 관리합니다. `package.json`의 `private: true`는 npm 게시를 막는 설정으로, GitHub나 사이트의 접근 권한과는 별개입니다.

## 카드 이미지와 크레딧

카드 이미지에는 Pamela Colman Smith가 그린 **원본 Rider–Waite–Smith(RWS)** 도안을 사용했습니다. 유니버셜 웨이트와 같은 카드 구조·상징을 따르지만, Mary Hanson-Roberts가 재채색한 상용 Universal Waite 이미지는 사용하지 않습니다. Pinterest 보드는 분위기와 카드 참고용이며, 해당 보드의 파일을 복사해 배포하지 않았습니다.

78장 이미지는 Wikimedia Commons의 퍼블릭 도메인 자료를 프로젝트에 포함했습니다. 카드별 원본 페이지, 이미지 주소, 저작자 표기는 [`public/cards/sources.json`](public/cards/sources.json)에, 수집과 출처에 대한 설명은 [`docs/card-art.md`](docs/card-art.md)에 있습니다. 도안의 기획은 Arthur Edward Waite, 그림은 Pamela Colman Smith의 작업입니다. 한국어 해설은 이 프로젝트에서 작성했습니다.
